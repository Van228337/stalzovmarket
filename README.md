# STALCRAFT Market Bot (STALZONE Scanner)

> Полностью бесплатный (0 ₽/$), автономный 24/7 сканер арбитражных сделок аукциона STALCRAFT RU.
> Работает в облаке GitHub Actions без необходимости держать включенным домашний ПК.

---

## ⚡ Принцип автономной работы 24/7 (Без включенного ПК)

Вам **не нужно** держать включенным свой компьютер:
1. Вы один раз загружаете проект в свой бесплатный **GitHub** репозиторий.
2. В репозитории настраиваете секреты (`Client ID`, `Client Secret`, `Telegram Token`, `Chat ID`).
3. Встроенный облачный планировщик **GitHub Actions** (`.github/workflows/collect-hot.yml`) автоматически запускается **каждые 5 минут**:
   - Опрашивает аукцион EXBO API (сервера GitHub не блокируются РКН и Cloudflare).
   - Анализирует честную цену, ликвидность, комиссию 5%, отсекает выбросы и манипуляции.
   - При нахождении выгодных сделок моментально присылает сигнал в ваш **Telegram**.
   - Генерирует дайджест для нейросетей.

---

## 🚀 Инструкция: Запуск в облаке за 3 шага

### Шаг 1. Создайте репозиторий на GitHub
1. Перейдите на [github.com/new](https://github.com/new).
2. Назовите репозиторий, например: `stalzone` или `stalcraft-market-bot`.
3. Сделайте его **Public** (в публичных репозиториях GitHub Actions полностью **бесплатны и безлимитны**).
4. **Не** ставьте галочки "Add a README" или ".gitignore" (репозиторий должен быть пустым).
5. Нажмите **Create repository**.

### Шаг 2. Отправьте код из папки в GitHub
В терминале PowerShell в папке проекта выполните команды:
```powershell
# 1. Привязка удаленного репозитория (замените ИМЯ_РЕПОЗИТОРИЯ на созданное):
git remote add origin https://github.com/Van228337/stalzone.git

# 2. Переименование ветки в master/main и отправка кода:
git branch -M master
git push -u origin master
```

### Шаг 3. Добавьте секреты в GitHub
В вашем созданном репозитории на GitHub:
1. Перейдите во вкладку **Settings** -> слева выберите **Secrets and variables** -> **Actions**.
2. Нажмите зеленую кнопку **New repository secret** и добавьте переменные:
   - `STALCRAFT_CLIENT_ID` — ваш Client ID (`3160`)
   - `STALCRAFT_CLIENT_SECRET` — ваш Client Secret
   - `TELEGRAM_BOT_TOKEN` — токен вашего Telegram-бота
   - `TELEGRAM_CHAT_ID` — ваш Telegram ID чата (`2026292229`)
   - `GROQ_API_KEY` — (опционально) ключ к Groq API

3. Перейдите во вкладку **Actions** на GitHub:
   - Нажмите **I understand my workflows, go ahead and enable them**.
   - Выберите слева воркфлоу **Collect Hot Market Lots & Signals** -> нажмите **Run workflow** для тестового запуска.
   - Всё! Бот запущен в облаке и будет работать каждые 5 минут круглые сутки.

## 📈 Стратегия и активы

- **Отказ от оружейных модулей:** Модули исключены из торговли из-за индивидуального разброса характеристик и низкой ликвидности.
- **Стандартизированные ликвидные активы (быстрый оборот в часах):**
  - **Медикаменты:** Военная аптечка (`g4lk0`, >500k продаж), Аптечка индивидуальная (`96430`, ~400k продаж), Аптечка ученых (`1r2o6`, ~250k продаж).
  - **Бронебойные патроны:** 7.62 мм БП (`g5np`, ~225k продаж), 5.45 мм БП (`ork0`, ~180k продаж), 9x39 мм СП-6 (`4dkn`, ~160k продаж).
  - **Популярное оружие:** ПП-91 «Кедр» (`96mj0`), «Гадюка» (`y1q9`).
- **Капитал:** 10,000,000 ₽ активного лимита (из общего банка 20кк), не более 30% на одну сделку.
- **Математика прибыли:**
  - Комиссия аукциона 5% вычитается из цены продажи:
    $$\text{Безубыток} = \frac{\text{Цена покупки}}{0.95} \approx \text{Цена покупки} \times 1.05263\ (+5.263\%)$$
  - Защита капитала: если даже при пессимистичной продаже по перцентилю $P_{25}$ прибыль отрицательна — сигнал **не формируется**.

## 🤖 Экспорт для нейросетей (ChatGPT, Claude, Grok, DeepSeek)

Каждый цикл сканирования формирует готовый дайджест:
1. **Файл:** `data/prompt_for_external_llm.txt` — уже содержит правила арбитража, текущую рыночную ситуацию, топ-3 сделки и запрос на экспертную оценку.
2. **В веб-интерфейсе:** Нажмите кнопку **«📋 Для нейросети»** в шапке дашборда — готовый текст мгновенно скопируется в буфер обмена. Просто вставьте его в диалог с любой моделью (ChatGPT, Claude, DeepSeek).
